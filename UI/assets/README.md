# LavaLabs logo

The shipped wordmark is **LavaLabs Volcano Logo.png**, supplied by the team. LavaLabs displays it with an SI-generated indicator. To override the header with a new icon, place **logo.svg**, **logo.png** or **logo.webp** here and refresh. Retain the required indicator for any SI-generated replacement in the public presentation and asset credits. The bundled geometric `volcano-placeholder.svg` provides the favicon and fallback.

This folder belongs to LavaLabs. No source SATQuery branding file is replaced.
