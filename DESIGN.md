# LavaLabs interface

The interface inherits SATQuery’s Scientific Noir palette and typography. The canvas is black, with graphite controls and off-white text. A warm red from the volcano wordmark marks the current tab, selected case and keyboard focus. Scientific colors retain their meanings in the maps and charts. Space Grotesk identifies sections, Geist carries reading text and IBM Plex Mono labels units and provenance.

The terrain is the focal point. The investigation and source trace sit alongside it on desktop and below it at narrow widths. The navigation links the five work areas without adding a landing page. Inputs and evidence remain reachable with a keyboard. The terrain case viewer provides a 2D map alternate, and optical no-data cells remain visible as gaps.

An analyst should be able to identify the selected variable, source and period, read the measured value and its limits, and download the underlying record. The case viewer pairs dates and valid coverage with the measurement. The trends page puts corrected p-values and the selected analysis period beside the chart.
